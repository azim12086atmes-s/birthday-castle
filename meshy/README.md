# Downloaded Meshy models

Original uploaded archives remain in this directory. The model folders added on 2026-10-16 contain extracted FBX meshes and their original textures. See [the checksum catalog](downloaded-models-2026-10-16.json) for source filenames, sizes, file hashes and storage types. These are source assets, not integrated or optimized game assets.

Large source files use Git LFS. Install Git LFS, then run `git lfs install` and `git lfs pull` after cloning. GitHub ZIP downloads can contain LFS pointers; use a Git LFS checkout to obtain the actual large files. Existing archive files can be extracted independently.
