# Castle of Starlight: Reference Art Table

> **Superseded for visuals by [image-analysis.md](image-analysis.md)** (built from the owner's own 20 images on 2026-10-10). Keep this table as background on sources only.

Living table of everything the owner's reference links show, broken into buildable pieces.
Each row points to its source page and, where one exists, an image id from [image-manifest.tsv](image-manifest.tsv). Once downloaded, the image is at `images/<ID>.<ext>`.

**Basis** says where a row's detail comes from:
- **page**: the article's own text and captions.
- **known**: well-documented knowledge of the named game's look, used where the page was blocked or showed no images.
- **image**: checked by looking at the downloaded picture. No rows have this yet, because the images could not be downloaded from the cloud machine (see [sources.md](sources.md)).

**Web cost** is for Three.js in a laptop browser: 🟢 cheap, do it; 🟡 moderate, needs care (instancing, LOD, low counts); 🔴 expensive, fake it or skip.

## 8. Performance techniques (what keeps it laptop-friendly)

| ID | Technique | Why it matters on the web | Source |
|---|---|---|---|
| P1 | **Unlit painted materials + a few emissive "light" planes** | Pedro Damasceno's scene uses no scene lights at all; shading is painted into the texture, mood comes from emissive planes. The cheapest path to a painterly look. | [Pedro Damasceno](https://www.exp-points.com/pedro-damasceno-stylized-art-from-concept) |
| P2 | **Bake lighting/AO into base color** | Light is folded into vertex colors or textures, so the GPU does almost nothing per light. | [80.lv VR world](https://80.lv/articles/building-a-stylized-game-world-for-vr), [80.lv stylized trend](https://80.lv/articles/following-the-stylized-trend-in-video-games), [80.lv Catalonia](https://80.lv/articles/from-concept-art-to-ue5-building-a-stylized-catalonia-inspired-town) |
| P3 | **Three texture atlases** | Exteriors, interiors, vegetation: three textures cover nearly every asset, so few draw calls and little memory. | [80.lv VR world](https://80.lv/articles/building-a-stylized-game-world-for-vr) |
| P4 | **Instanced modular kits** | Reuse a small set of pieces; Three.js InstancedMesh draws hundreds in one call. | [80.lv Catalonia](https://80.lv/articles/from-concept-art-to-ue5-building-a-stylized-catalonia-inspired-town), [Magic Moorland](https://www.exp-points.com/julia-cui-magic-moorland) |
| P5 | **No shadows on foliage; shadows off far away** | Shadow maps are the most expensive thing in a forest. | [Magic Moorland](https://www.exp-points.com/julia-cui-magic-moorland), [80.lv painterly world](https://80.lv/articles/turning-2d-concept-art-into-a-detailed-painterly-3d-world) |
| P6 | **Painted backdrops and card forests** | Distance is painted, not modeled. | [kidswithsticks](https://kidswithsticks.com/creating-stylized-art-inspired-by-ghibli-using-unreal-engine-4/), [80.lv vast landscapes](https://80.lv/articles/001agt-creating-vast-landscapes-in-ue4) |
| P7 | **Plan optimization from day one** | Retrofitting performance at the end does not work. | [80.lv VR world](https://80.lv/articles/building-a-stylized-game-world-for-vr) |
| P8 | **Things to skip** | Ray tracing, real-time GI (Lumen), distance-field AO, real reflections, SpeedTree-density forests: all 🔴 in a browser. Fake them with baked color, fog and emissive. | [80.lv Lost civilization](https://80.lv/articles/001agt-003qxl-005cg-lost-of-civilization-organic-environment-art-in-ue4) (ran at 20–45 FPS on a desktop with RT off) |
