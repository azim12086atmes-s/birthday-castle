## What the image shows

The current proposal hasFC04–FC06 cottage clearings, FT02 loop/branches, FD02 pond, coastal edges and mixed canopy symbols. Existing B12 cottage/trail/natural sheets provide component ideas but no built forest or tested route.

## Proposed layout and experience

Enter from village cobble onto an earth path through hazel/birch edge planting. PlaceFC04 in a quieter oak grove, FC05 beside a willow/fern pond nook, andFC06 at a sunny coastal orchard/meadow edge. A main loop plus a short return spur creates choices; logs, benches and small lamps mark selected rest/discovery spots rather than constant clutter.

This paragraph describes an imagined, source-compatible arrangement. Hidden backs, room depths, elevations and exact routes are not recovered measurements.
