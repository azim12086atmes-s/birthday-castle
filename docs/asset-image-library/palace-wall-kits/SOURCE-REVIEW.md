# Focused wall source review

GEN-37 controls the palace's front composition. GEN-43 supplies the existing lower pointed-arcade appearance. GEN-38 supplies great-window and medium-gallery glazing. GEN-19 and GEN-42 provide existing portal, moulding, cornice and return vocabulary. The source boards were reviewed individually.

The generated sheets infer complete backs, wall thickness and angular junctions; they are not exact measured source geometry. Glazing, capitals and carving families should be reused as independent assets when models are built. L3/L4 share the same confirmed 70-grid-m rise, which permits a proposed shared wall-body family without regenerating every ornament.

The owner subsequently requested screenshot-led segmentation, one family at a time. These early wall packs remain saved for later comparison; they are not automatically accepted as the final wall designs.
