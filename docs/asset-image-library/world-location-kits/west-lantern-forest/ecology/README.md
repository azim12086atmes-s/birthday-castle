## Review

**F02-FLORA-001**

Four named canopy forms are present with root feet, proposed heights and leaf/bark insets. Oak, birch, beech and multi-stem hazel are newly proposed woodland forms; GEN-09 supplies the rendering vocabulary, not these exact species models.

Small canopy-outline insets are front silhouettes, not verified overhead crown plans. Leaf/nut interpretation, branch count, bark texture, backs and root contact need modelling review; they are not botanically validated specimens or seamless texture maps.

Use local species mixtures, saplings and density changes rather than duplicate identical trees everywhere. Canopy/leaf geometry, alpha materials, wind, LOD and runtime performance remain unbuilt.

**F02-FAUNA-001**

All four labelled mammals have a large profile/three-quarter view plus front/rear views. Doe has no antlers; fox/hare/squirrel have coherent ordinary woodland forms and single tails. Printed dimensions match the proposed values.

These are imaginative naturalistic references without a supplied animal image. View-to-view shape/pose parity, exact limb/toe anatomy, skeletal joints, fur, topology, UVs and support are not proven by the illustrations.

The artwork is not a rig, locomotion cycle or completed character. Body proportions and pose must be locked on model intake before animal movement/behavior is claimed.

**F02-FAUNA-002**

All twelve named groups are present. The revision repacks six birds and six insects into four columns and three rows without the first draft’s blank cells.

Birds are shown at rest with folded wings and smaller back views; flight forms remain missing. Insect wing/leg roots, fine legs, antennae and undersides are not fully resolved. Species markings are inspired illustrations rather than validated anatomy or identical mesh projections.

Each cell uses an independent illustration scale. Count main species IDs once despite smaller duplicate views. Mask labels/insets deliberately before model intake; mesh splitting, translucency, rigging, flight and behavior remain unverified.
