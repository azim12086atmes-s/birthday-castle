## Already drawn: extract or fit these

- **Loose seat/throw cushions**: Chaise source already shows cushions; GEN-20 also supplies cushion construction/embroidery. Isolate existing cushion shape/embroidery. Extra styles are optional, not a proven missing master.
- **Table candles and candlesticks**: Visible on the original wish table. Extract visible parts; add another view only if shaft/base/back remains ambiguous. Do not create a new candle style by default.
- **Curtain rod, finials, tiebacks and tassels**: Explicit detail panels in existing curtain source. Index/isolate existing detail parts and normalize span/mounts.
- **Pearl strings, hanging loops and moon/star charms**: Festoon source includes pearl/chain/charm/ring details. Use existing motifs; define repeat segment and end attachment lengths.
- **Floral clusters and ribbon swags**: Existing floral arch/swag assembly and detailed cluster source. Reuse/isolate existing clusters, not another generic bouquet pack.
- **Garland/banner hanging brackets**: An indexed garland hanging bracket and banner mounting design already exist. Compare mounting face/scale to interior support; generate a new adapter only if actual fit requires it.
- **Table flower vase/bowl**: A flower vessel and star bowl already appear on the wish table. Isolate existing vessels; no new centerpiece-vase master yet.
- **Rug, embroidered tablecloth and long runner motifs**: Rug border/corner and tablecloth embroidery/corner/tassel details exist. Reuse source textile motifs; a long runner needs length/repeat/end planning, not an unrelated new floor or cloth design.
